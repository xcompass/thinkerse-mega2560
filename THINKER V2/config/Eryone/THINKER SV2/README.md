# Thinker SV2 configurations (Marlin 2.0.x)

These configurations and the matching files in `Hex File/THINKER SV2/` are Eryone's
Marlin 2.0.x versions. They have not been ported to Marlin 2.1.2.9 and do not build
with the Marlin 2.1.2.9 tree in `THINKER V2/Marlin`. The Marlin 2.0.x tree they belong
to is in the history of the `master` branch.
